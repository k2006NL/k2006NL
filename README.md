#### 研究：法律 × RAG

- RAG（検索拡張生成）の回答が、どの文書のどの部分を根拠にしているかを追跡する研究（Answer Attribution）
- きっかけは、LLMに条例を書かせると、国の法律と矛盾したものが出てくると確かめたこと。原因は、生成の根拠が見えないことにあると考えた
- YANS 2026 でポスター発表
- RAGの評価タスク（R2C2）にチームで参加。根拠候補の絞り込みを担当し、引用されている文書に絞ることで処理対象を86%減らした
