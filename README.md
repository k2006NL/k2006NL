#### 研究：RAG の忠実性

- RAG（検索拡張生成）で、LLM が自分の事前知識より、渡された文書に沿って答えるようにする研究
- LLM の Feed-Forward 層への介入が、長い回答の生成にどう影響するかを、統計的な検定と LLM-as-a-Judge で分析。YANS 2026 でポスター発表
- RAGの評価タスク（R2C2）にチームで参加。根拠候補の絞り込みを担当し、引用されている文書に絞ることで処理対象を86%減らした
